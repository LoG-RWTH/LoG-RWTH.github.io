# Learning on Graphs: Minion Pro and Myriad Pro

Complete font alternative for the group website. Minion Pro is used for headings and Myriad Pro for the body and navigation. All text, members, images, colors, sizes, links, and spacing are preserved from the existing group homepage.

The local preview uses existing fonts available on this Mac during the current login session. To use the fonts for all visitors, add your Adobe Fonts web-project stylesheet link to the head of index.html. Include Minion Pro and Myriad Pro regular, italic and bold styles, plus Myriad Pro semibold. CSS already prioritizes minion-pro and myriad-pro. Without those fonts, the website uses fallbacks.

No commercial font binaries are included. Setup: https://helpx.adobe.com/fonts/web/web-design-and-development/add-fonts-website.html

After connecting the web project, use these files in the existing GitHub Pages publishing folder. This package has not been published.
